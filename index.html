REST API Reference

Makes of Cars

Contains information on all makes of cars as registered by united states department of transportation.

Endpoint

GET api/vehicles/getallmakes

Returns a list of makes of cars.

Parameters

Query String Parameters

Parameter Required/Optional Description Type
format Optional The desired response format. Default is xml string
Example: json, csv, xml

Sample Request

curl -X GET "https://vpic.nhtsa.dot.gov/api/vehicles/getallmakes?format=json"

In Postman: Import → Paste cURL.

Response Description

The following tabe describes each item in the response.

Response Item Description Data Type
Count The number of car makes returned by the request. Integer
Message The success or failure status of the HTTP request. value ranges from "No HTTP request was found" to "Response returned successfully". String
SearchCriteria A filter to narrow down search result with defualt set to null, if set to null or ommited, the API performs a broad search. Object | null
Results The car makes details represented as array of objects. Object | array
Results/Make_ID The car make identifier, its unique to each car. Integer
Results/Make_Name The car make name, String
